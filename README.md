 # 🛕 Temple Dash – Ancient India Runner Game >

<img width="1200" height="900" alt="temple" src="https://github.com/user-attachments/assets/bf6c430c-b60b-4ce4-862d-fc6d7a203a5c" />



A fun endless runner game inspired by Temple Run, built using pure HTML, CSS, and JavaScript.

The player runs through an ancient Indian temple road while escaping from a tiger 🐅, collecting rupee coins 🪙, and avoiding obstacles.

---

# 🎮 Features

- Endless runner gameplay
- Smooth lane switching
- Jump & slide mechanics
- Indian-themed environment
- Tiger chase animation
- Coin collection system
- Lives system ❤️
- Dynamic obstacles
- Mobile touch controls
- Responsive full-screen gameplay
- Pure Vanilla JavaScript (No libraries)

---

# 🕹 Controls

| Action | Keyboard |
|--------|-----------|
| Move Left | ← / A |
| Move Right | → / D |
| Jump | ↑ / W / Space |
| Slide | ↓ / S |

### 📱 Mobile Controls
- Swipe Left → Move Left
- Swipe Right → Move Right
- Swipe Up → Jump
- Swipe Down → Slide

# 🚀 How to Run

## Method 1 — Direct Open
Simply open the `index.html` file in your browser.

---

## Method 2 — VS Code Live Server

1. Install VS Code
2. Install the "Live Server" extension
3. Open the project folder
4. Right click `index.html`
5. Click:

```bash
Open with Live Server
```

# 📈 Gameplay Mechanics

- Speed increases gradually
- Score increases over time
- Coins increase score potential
- Collision decreases lives
- Game ends when all lives are lost
